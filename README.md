# MSc Project Experiment Archive

This repository contains the experiment archive used for the MSc dissertation. It combines records collected from the local project and the `mitkof` server on 12 September 2026.

The archive was created from existing outputs. No models were retrained or re-evaluated.

## Start here

Open [msc_project_experiment_index.xlsx](msc_project_experiment_index.xlsx) for the experiment summary.

Keep the workbook, this README, and the `msc project data` directory in their current relative locations because the workbook contains relative links to archived files.
